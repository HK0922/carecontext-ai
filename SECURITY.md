# Security

This is a synthetic, local, single-user prototype. It has no production authentication or clinical compliance certification. Do not expose it publicly or use real patient data without a separate deployment review and the required controls.

If you find a security issue, do not post credentials or sensitive data in a public issue. After the repository is published, use GitHub private vulnerability reporting if enabled, or contact the maintainer through the GitHub profile to arrange a private report. No dedicated security inbox is currently configured.

Include affected version, a synthetic reproduction, impact, and a suggested mitigation. No response SLA is promised. The current prototype version is 0.1.x.
