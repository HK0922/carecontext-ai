# Visual design

The interface uses a clinical editorial style: warm ivory canvas, muted green controls, white evidence panels, and serif page headings. The case queue, evidence brief, and timeline stay visually distinct without a marketing landing-page layer.

| Token | Value |
| --- | --- |
| Background | #f7f8f3 |
| Ink | #203932 |
| Primary | #244b43 |
| Border | #dfe4da |
| Accent | #dcebc7 |
| Heading font | Georgia, system serif |
| Body font | Arial, system sans-serif |

The UI is designed to stack at tablet and mobile breakpoints. It uses visible keyboard focus, semantic forms, labeled inputs, native dialogs, status regions, and reduced-motion support. These choices are implemented but have not been verified with a browser or assistive technology in this build environment.

The README banner is a local PNG so it renders without an external asset host. Its source is the included asset-generation script. It is a branded diagram, not a screenshot of the running app.
