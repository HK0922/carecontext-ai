DEVELOPER REFERENCE

Evidence, through an API.

All endpoints operate on the bundled synthetic cases. No patient upload or clinical action endpoint exists.

Session header

Fetch GET /api/config, then send its session value as X-CareContext-Session on POST and DELETE requests. This is a same-origin request control, not authentication. Reload after server restart.

Routes

RequestPurpose
GET /api/patientsList synthetic cases
GET /api/patients/{id}Timeline and differing entries
GET /api/sources?patient_id=demo-001Scoped source passages
POST /api/queryRetrieve a new evidence brief
POST /api/verifyCheck complete source excerpts
GET /api/history/{patient_id}Saved question history
DELETE /api/history/{patient_id}Delete this case's review history
GET /api/runs/{run_id}Saved evidence snapshot
POST /api/runs/{run_id}/reviewSave review decision and note
GET /api/runs/{run_id}/exportDownload Markdown; add ?format=json for JSON
POST /api/evaluationsRun the local labeled fixture suite
