# Three minute demonstration

Start the app using README instructions. Show local mode so the recording is reproducible without credentials. This is a suggested walkthrough, not a report of completed browser testing.

1. **The problem, 20 seconds.** Explain that clinical record questions need inspectable sources and context. State that every person and document is fictional.
2. **Retrieve, 35 seconds.** Select Maya Chen. Click “What allergy information changed?” Point to the numbered citations and dated source titles.
3. **Inspect, 35 seconds.** Open a citation. Show the full record and highlighted passage. Expand the differing-values notice. The earlier and later entries remain visible.
4. **Test uncertainty, 25 seconds.** Ask “Is an HbA1c result available?” Show the evidence gap. Explain why missing evidence is not a negative finding.
5. **Filter history, 20 seconds.** Ask the allergy question with a cutoff of 2026-05-07. Only the earlier intake entry is eligible. The timeline still shows the full case history.
6. **Review, 20 seconds.** Add “Reconcile the allergy entries.” Mark needs follow-up, then export the Markdown brief.
7. **Measure, 25 seconds.** Run the Evaluation lab. Explain that 24 fixture checks pass on a small author-written corpus, not a clinical benchmark.

Optional: open “Check a source excerpt,” change a medication name in the copied text, and run the checker. The modified text should be unverified. This is a provenance check, not a medical fact checker.
