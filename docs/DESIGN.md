# CareContext design system

Current Studio v0.3 design: [Editorial Design System](EDITORIAL_DESIGN_SYSTEM.md).

The Studio visual system was adapted from the user-provided `DESIGN.md` specification: an off-white editorial canvas, light serif display typography, warm ink primary actions, hairline borders, pill buttons, and pastel atmospheric orbs. CareContext retains its own identity and doesn't bundle or use the reference brand's licensed font.

The preserved v0.2 **Classic workspace** uses its earlier clinical-editorial design and remains available at `/classic` for compatibility and source comparison.
